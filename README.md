# PX4 + MPC 无人机学习笔记

> px4_mpc_drone_note：记录学习过程中的笔记、复现过程、问题解决办法、创新和优化。

这是一套面向 **PX4、ROS 2、MPC/NMPC、真机部署和求职** 的长期学习笔记仓库。目标不是收集资料，而是持续沉淀“理解、代码、实验结果、可写进简历的产出”。

**目标岗位**：飞控算法、运控算法、规控算法、机器人软件、嵌入式软件。

**核心主线**：工程基础 -> 控制与 MPC -> PX4 仿真闭环 -> 真机与论文 -> RL 对比 -> MPC x Learning -> 项目与求职。

## 从哪里开始

1. 第一次使用：阅读 [第一次使用清单](00-开始这里/第一次使用清单.md)。

4. 找到当前阶段：进入 [学习阶段目录](10-学习阶段/README.md)。
5. 每周六写周报：复制 [周报模板](70-周报/周报模板.md)。

## 每周最小闭环

```text
选本周任务 -> 学习/复现 -> 留下代码或实验 -> 写知识笔记
          -> 更新项目与验收 -> 写周报 -> 下周只改 3 件事
```

一个任务只有同时满足下面两点，才算真正完成：

- 能从零复现或独立解释，不依赖原教程。
- 仓库里有可检查的产出：代码、图、表、复现记录或问答。
