# 第一次使用清单

目标：用半天完成个人定位、目录确认和第一篇笔记，不安装复杂软件。

## 1. 确认仓库

- [ ] 打开 GitHub 仓库：<https://github.com/XtangUser/px4_mpc_drone_note>
- [ ] 本地目录已经是 Git 仓库。
- [ ] 能执行 `git status` 并看到当前修改。
- [ ] 已配置 Git 用户名和邮箱。
- [ ] 已配置 GitHub SSH key 或 Personal Access Token。

```bash
git config --global user.name "你的名字"
git config --global user.email "你的邮箱"
git status
```

## 2. 做自测

按 [MPC 无人机学习手册的 Step 0.1](../MPC无人机学习手册.md) 给自己打分。

- [ ] C++ 基础自测完成。
- [ ] Linux 与 Git 自测完成。
- [ ] ROS 2 自测完成。
- [ ] 控制理论自测完成。
- [ ] 数学与 Python 自测完成。

将结果写入 [学习进度](学习进度.md) 的“个人起点”区。

## 3. 选择硬件路线

- [ ] 根据 [环境与硬件选择](环境与硬件选择.md) 选择 A、B 或 C。
- [ ] 记录显卡、内存、操作系统和可用于真机的设备。
- [ ] 将环境信息写入 [环境版本清单](../80-资源/环境版本清单.md)。

## 4. 建立第一篇周报

- [ ] 复制 [周报模板](../70-周报/周报模板.md)。
- [ ] 在 `70-周报/` 中新建 `W01.md`。
- [ ] 写明 W1 的唯一主目标：搭好基础环境并完成自测。
- [ ] 写明本周可交付的证据。

文件名建议：

```text
70-周报/
├── W01.md
├── W02.md
└── W03.md
```

## 5. 完成第一次提交

```bash
git add .
git commit -m "docs: initialize learning notes framework"
git push origin main
```

如果远端已有内容，先执行：

```bash
git pull --rebase origin main
```

## 完成标准

- [ ] 已确定当前周次和阶段。
- [ ] 已确定硬件路线。
- [ ] 已写第一篇周报。
- [ ] 已向 GitHub 提交一次。
