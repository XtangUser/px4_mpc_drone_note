# 开始这里

这个目录负责回答三个问题：

- 我现在应该做什么？
- 做到什么程度算完成？
- 学习结果放在哪里？

## 阅读顺序

1. [第一次使用清单](第一次使用清单.md)：用半天完成仓库初始化和个人定位。
2. [6 步学习法](6步学习法.md)：统一“看、读、跑、改、创、写”的执行标准。
3. [环境与硬件选择](环境与硬件选择.md)：先确定仿真、训练和真机路线。
4. [学习进度](学习进度.md)：每周维护一次状态和下一步。

## 笔记分层

| 类型 | 放在哪里 | 回答的问题 |
|---|---|---|
| 阶段笔记 | `10-学习阶段/` | 这一阶段要完成什么？ |
| 知识笔记 | `30-知识库/` | 原理是什么？为什么这样设计？ |
| 项目记录 | `20-项目/` | 我做了什么？如何复现？ |
| 论文笔记 | `40-论文/` | 论文解决什么问题？我还能改什么？ |
| 实验记录 | `50-实验/` | 在什么条件下得到了什么结果？ |
| 周报 | `70-周报/` | 本周做了什么？卡在哪里？ |
| 求职资产 | `60-求职/` | 这些经历如何转化为简历和面试答案？ |

不要求一次写完整。先留下可继续编辑的骨架，再随着学习补证据。
