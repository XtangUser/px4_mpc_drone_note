# 论文笔记

论文笔记的目标是形成研究判断，不是翻译摘要。

一篇合格笔记必须回答：

1. 它真正要解决的问题是什么？
2. 之前的方法为什么不够？
3. 核心假设是否适用于我的平台？
4. 哪组实验真正支持结论？
5. 代码能不能复现，缺了什么？
6. 如果接进自己的 NMPC，改动点在哪里？

## 使用方式

- 每篇论文复制 [论文笔记模板](论文笔记模板.md)。
- 在 [论文索引](论文索引.md) 登记状态和代码。
- 需要复现时，在 `50-实验/` 建实验记录。
