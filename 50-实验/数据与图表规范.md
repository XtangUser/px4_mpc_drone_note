# 数据与图表规范

## 文件命名

```text
日期_平台_控制器_轨迹_工况_序号
```

示例：

```text
20270415_x500_nmpc-dob_fig8_wind_03
```

## 目录建议

```text
data/
├── raw/          # 原始 rosbag、csv、log，不手工修改
├── processed/    # 脚本生成的数据
├── figures/      # 论文和报告图
├── configs/      # 参数和实验配置
└── private/      # 本地数据，不提交 GitHub
```

默认只提交小型处理结果和生成脚本。大文件使用 Git LFS 或外部存储，并记录校验信息。

## 每次实验必须记录

- 代码 commit 或 tag。
- 固件和软件版本。
- 参数 YAML。
- 日期、时间、场地、风况、负载。
- 电池电压或供电条件。
- 原始数据文件。
- 评价指标和生成图表的命令。

## 统一指标

- 位置 RMSE。
- 最大位置误差。
- 求解时间均值。
- 求解时间 P99。
- 求解时间最大值。
- CPU 占用。
- 控制输入平滑度。
- 约束违反次数和持续时间。

## 图表规则

- 同一控制器在所有图中使用同一种颜色。
- 坐标轴包含物理量和单位。
- 图题说明工况和重复次数。
- 误差图同时给出均值和波动范围。
- 论文图必须由脚本生成，不手工修改数据。
