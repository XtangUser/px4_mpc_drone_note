# 实验记录

实验记录回答：在什么条件下，与什么基线相比，得到什么结果，是否可以复现。

## 使用方式

1. 复制 [实验记录模板](实验记录模板.md)。
2. 按 [数据与图表规范](数据与图表规范.md) 命名数据和图。
3. 每次正式实验更新本页索引。
4. 论文中的图必须能由脚本从原始数据重新生成。
