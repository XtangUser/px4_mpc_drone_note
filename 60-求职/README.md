# 求职资产

求职不是最后一个月写简历，而是把平时的项目和实验持续转成可验证的证据。

## 文件

| 文件 | 用途 | 更新频率 |
|---|---|---|
| [技能矩阵](技能矩阵.md) | 对比岗位要求和自身能力 | 每月 |
| [简历项目池](简历项目池.md) | 提炼项目量化描述 | 项目里程碑后 |
| [面试题库](面试题库.md) | 写书面答案和复盘 | 每周 |
| [投递记录](投递记录.md) | 记录公司、岗位、流程和复盘 | 投递期间 |

## 岗位主线

- 飞控算法工程师。
- 运控算法工程师。
- 规控算法工程师。
- 机器人软件工程师。
- 嵌入式软件工程师。
