# 项目作品集

项目目录只记录能展示给面试官的内容：目标、架构、复现、改造、实验、结果和演示。

## 项目使用方式

1. 启动项目时复制 [项目模板](项目模板.md)。
2. 项目过程中把实验写入 `50-实验/`，不要把所有内容堆在 README。
3. 每完成一个里程碑，更新 [项目索引](项目索引.md)。
4. 投简历前，把项目压缩成 [简历项目池](../60-求职/简历项目池.md) 中的量化描述。
5. 复现开源项目时使用 [复现报告模板](复现报告模板.md)。

## 项目标准

每个作品集项目至少包含：

- 一句话问题定义和价值。
- 系统架构图。
- 核心模型、算法或控制结构说明。
- 环境与版本。
- 从零复现步骤。
- 基线与对比方法。
- 量化结果。
- 失败案例和边界条件。
- GIF 或视频。
