## 阶段更新规则

进入阶段时：

- 把状态改为“进行中”。
- 写清本阶段的目标、验收和风险。
- 从 [周报模板](../70-周报/周报模板.md) 新建本周周报。

退出阶段时：

- 逐项检查验收。
- 把代码、图、表、视频链接补到“阶段产物”。
- 更新 [学习进度](../00-开始这里/学习进度.md)。
- 在项目或实验目录留下可复现证据。
