# 阶段 3：PX4 + MPC 仿真闭环

## 阶段目标

在 PX4 SITL 中跑通并改造一个 ROS 2 + acados 的 MPC，完成论文 1 的仿真实验。

## 核心任务

### 四旋翼与控制架构

- [ ] 手推四旋翼平动和转动方程。
- [ ] 理解 SE(3) 几何控制和 minimum-snap。
- [ ] 在 RotorPy 中运行基础仿真。
- [ ] 用 acados NMPC 替换 RotorPy 控制器并与 SE(3) 比较。
- [ ] 画出 PX4 位置、速度、姿态、角速度串级控制图。
- [ ] 标出外部 MPC 可接入的层级和优缺点。

### 复现 px4-mpc

- [ ] 启动 PX4 SITL、Agent、RViz 和 px4-mpc。
- [ ] 在 RViz 中改变目标点，让飞机跟踪。
- [ ] 找到状态量、控制量、模型文件、求解器配置和 PX4 话题。
- [ ] 按 [复现报告模板](../20-项目/复现报告模板.md) 写复现记录。

### 改造

- [ ] 把目标点改为圆、8 字和 minimum-snap 时变轨迹。
- [ ] 写 `eval_bag.py`，自动计算 RMSE、最大误差、求解时间均值/P99/最大值。
- [ ] 把 Python 节点改写为 C++ 节点。
- [ ] 同一条轨迹与 PX4 默认位置控制器做基线对比。

### 抗扰实验

- [ ] 使用 windy 仿真世界。
- [ ] 让模型质量错 20%，模拟负载失配。
- [ ] 实现扰动观测器或残差学习的一种。
- [ ] 对比 PID、NMPC、NMPC+DOB/残差在三种工况下的 RMSE。
- [ ] 完成论文仿真章节初稿。

## 验收

- [ ] px4-mpc 在 SITL 中正常工作。
- [ ] C++ 节点稳定运行在 50 Hz 以上，P99 小于控制周期。

- [ ] 有抗扰对比表、图和仿真章节初稿。
