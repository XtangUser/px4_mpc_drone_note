# 阶段 1：工程基础

## 阶段目标

把面试必考的 C++、Linux、ROS 2 打牢，并写出第一个能控制 PX4 的 C++ ROS 2 节点。

## 核心任务

### C++ 与并发

- [ ] 用 CMake 和 GoogleTest 建立 C++ 工程模板。
- [ ] 实现线程安全环形缓冲区，包含阻塞和非阻塞接口。
- [ ] 实现线程池，使用任务队列、条件变量和 future。
- [ ] 实现异步日志器，用 perf 分析热点。
- [ ] 手写简化版 `shared_ptr`。

### Linux 与工具链

- [ ] 掌握 Shell、Git、gdb、perf 和 CMake 基础。
- [ ] 写 `sim_up.sh`，用 tmux 一键启动 Agent、PX4 SITL 和控制节点。
- [ ] 掌握分支、rebase、冲突处理和规范 commit message。

### ROS 2 深入

- [ ] 理解 Executor、callback group、QoS 和 lifecycle。
- [ ] 跑通 composition 和 intra-process demo。
- [ ] 跑通 ros2_control_demos example_1。
- [ ] 用 C++ 写画圆 Offboard 节点。
- [ ] 参数 YAML 和 launch 文件可配置半径与角速度。

### 数据闭环

- [ ] 用 rosbag2 录制里程计和设定点。
- [ ] 用 PlotJuggler 画位置误差曲线。
- [ ] 对比无前馈、速度前馈、速度和加速度前馈。

### 刷题

- [ ] W3-W16 按代码随想录顺序完成第一轮。
- [ ] 每天 30-45 分钟，记录思路、复杂度和易错点。

## 验收

- [ ] 3 个 C++ 小项目单测全部通过，valgrind 无泄漏。
- [ ] RRBot 能在 RViz 中正常运行。
- [ ] PX4 SITL 中飞机在 3 m 高度、半径 2 m 画圆。
- [ ] 能解释 QoS 不匹配为什么导致收不到数据。
- [ ] 能解释 CPU、进程、线程和多线程同步的基本概念。
