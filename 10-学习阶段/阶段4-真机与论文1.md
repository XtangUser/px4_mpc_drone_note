# 阶段 4：真机与论文 1

## 阶段目标

把 NMPC 安全地迁移到真机，获得对比数据和演示视频，并在 W40 前完成论文 1 定稿。

## 真机安全底线

- [ ] 只在室外空旷场地或网笼内飞行。
- [ ] 每次飞行安排安全员并保持遥控器可随时接管。
- [ ] 先系绳，再低空、低速。
- [ ] 每次起飞前完成 [飞前检查清单](../MPC无人机学习手册.md)。
- [ ] 程序始终有输出限幅、超时兜底和急停方案。

## 硬件与定位

- [ ] 确定无人机平台，记录机架、飞控、电调、桨叶和电池配置。
- [ ] 按手动、定高、定点顺序完成基础试飞。
- [ ] 用 PX4 Flight Review 分析日志并调参。
- [ ] 在机载电脑安装 Ubuntu、ROS 2、Agent。
- [ ] 打通机载电脑与 PX4 的 uXRCE-DDS。
- [ ] 选择动捕、VIO 或 GPS 定位方案。
- [ ] 将外部位姿送入 EKF2 并统计悬停标准差。

## 真机推进顺序

- [ ] Offboard 悬停。
- [ ] PX4 位置控制器低速圆轨迹，采集基线。
- [ ] NMPC 悬停。
- [ ] NMPC 圆和 8 字，按 0.5、1、2 m/s 逐步提速。
- [ ] 偏心负载与风扇侧风实验。
- [ ] 采集机载计算时间和抖动数据。
- [ ] 制作 1 分钟演示视频。

## 论文 1

- [ ] 建立相关工作文献表。
- [ ] 完成方法章节。
- [ ] 完成仿真与真机实验章节。
- [ ] 统一字体、线宽、配色和指标。
- [ ] 完成摘要、引言和结论。
- [ ] 导师完成至少两轮修改。
