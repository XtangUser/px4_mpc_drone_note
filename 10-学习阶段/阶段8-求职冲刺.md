# 阶段 8：求职冲刺

## 阶段目标

把三年的学习和项目转成简历、面试答案、实习机会和最终 offer。

## 简历与 GitHub

- [ ] 完成简历 v1。
- [ ] 精修三个项目的 README。
- [ ] 每个项目包含架构图、复现步骤、实验数据和演示视频。
- [ ] 用统一指标描述性能：RMSE、P99、频率、CPU 占用。
- [ ] 在简历中放入 GitHub 和视频链接。

## 面试准备

- [ ] 复习 C++：内存、智能指针、虚函数、STL、并发。
- [ ] 复习 Linux：进程、线程、调度、IPC、实时性。
- [ ] 复习网络：TCP/UDP、延迟、拥塞。
- [ ] 复习 ROS 2：DDS、QoS、executor、零拷贝、lifecycle。
- [ ] 复习控制：LQR、MPC、NMPC、稳定性、约束、时延。
- [ ] 为附录 G 的每道题写书面答案。
- [ ] W67 起刷 LeetCode Hot 100 第二遍。
- [ ] 每周至少两次限时模拟。

## 投递

- [ ] 整理目标公司、岗位、截止时间、笔试时间和内推码。
- [ ] W68 投寒假日常实习。
- [ ] W75-W78 投暑期实习。
- [ ] 记录每次投递、笔试、面试和复盘。
- [ ] 2028-07 起准备秋招提前批和正式批。

## 面试项目叙述模板

每个项目准备四个版本：

1. 30 秒：做了什么，技术是什么，量化结果是什么。
2. 2 分钟：问题、方案、取舍、结果。
3. 10 分钟：架构、模型、代码、实验、失败案例。
4. 深挖版：为什么不用替代方案，边界条件是什么。

## 验收

- [ ] 简历没有未量化、无法解释的表述。
- [ ] 三个项目都能从零演示或复现。
- [ ] 高频题有书面答案。
- [ ] 投递记录完整。
- [ ] 每场面试后 24 小时内完成复盘。
