# 阶段 0：环境与首飞

## 阶段目标

在两周内完成开发环境，并让 ROS 2 程序控制 PX4 SITL 中的 x500 自动起飞到 5 m。这个阶段的目标是建立信心，不是深入原理。

## 进入条件

- [ ] 已阅读 [第一次使用清单](../00-开始这里/第一次使用清单.md)。
- [ ] 已确定硬件路线。
- [ ] 已准备 Ubuntu 22.04 双系统或计划在本周安装。

## 任务

### 0.1 自测与定位

- [ ] 按 C++、Linux、ROS 2、控制、数学、Python 六个方向完成自测。
- [ ] 给每道题填 0-2 分，记录证据或缺口。
- [ ] 把结果写入 [学习进度](../00-开始这里/学习进度.md)。

### 0.2 安装系统与工具

- [ ] 安装 Ubuntu 22.04、推荐显卡驱动和常用开发工具。
- [ ] 安装 ROS 2 Humble。
- [ ] 配置 VSCode、C++、Python、CMake、ROS 插件。
- [ ] 配置 GitHub SSH key。
- [ ] 运行 talker/listener 验证 ROS 2。

### 0.3 PX4 SITL 与 Offboard

- [ ] 下载并编译 PX4-Autopilot。
- [ ] 建立 `px4_msgs`、`px4_ros_com`、Micro-XRCE-DDS Agent 工作空间。
- [ ] 启动 QGroundControl、Agent、PX4 SITL。
- [ ] 运行官方 Offboard 示例，让飞机升到 5 m。
- [ ] 用 `ros2 topic list` 找到 `/fmu/out` 和 `/fmu/in` 话题。

### 0.4 学习仓库与第一篇周报

- [ ] 确认本仓库能提交到 GitHub。
- [ ] 复制周报模板，新建 `W01.md` 和 `W02.md`。
- [ ] 从 W1 开始每天刷一道题。

## 验收

- [ ] talker/listener 能互相通信。
- [ ] PX4 SITL 中 x500 自动解锁并升到 5 m 后悬停。
- [ ] 能解释 Agent 和 Client 分别运行在哪里。
- [ ] 能解释为什么订阅 PX4 话题要用 SensorDataQoS。
- [ ] 能解释 NED/FRD 与 ENU/FLU 的区别。
- [ ] 能提交并推送第一篇周报。
