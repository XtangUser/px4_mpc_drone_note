# 阶段 7：差异化项目二选一

## 目的

用第三个项目形成一个清晰标签：

- Track A：嵌入式 + 控制，突出实时部署能力。
- Track B：全链路自主，突出系统集成能力。

只选一条主路线，另一条只保留了解。

## Track A：嵌入式 MPC

- [ ] 学习 FreeRTOS 或 RTOS 基础。
- [ ] 跑通 TinyMPC Python 示例。
- [ ] 了解 TinyMPC 代码生成。
- [ ] 在 STM32 或 Crazyflie 上运行 MPC。
- [ ] 测量控制频率、单次求解时间、RAM 和 Flash。
- [ ] 用 NMPC 数据训练小 MLP，近似 MPC。
- [ ] 对比 TinyMPC 和 MLP 的精度、耗时与资源占用。
- [ ] 录制演示视频。

验收：

- [ ] 控制频率达到 100 Hz，或给出明确瓶颈分析。
- [ ] 有资源占用表和实时性分布。
- [ ] 有失败安全和超时兜底。

## Track B：全链路自主飞行

- [ ] 跑通 EGO-Planner 或 EGO-Swarm ROS 2 分支。
- [ ] 选择 FAST-LIO 或 VINS-Fusion。
- [ ] 打通“规划器 -> NMPC -> uXRCE-DDS -> PX4”。
- [ ] 在仿真中完成未知环境避障和到点。
- [ ] 有条件时进行真机穿越障碍。
- [ ] 录制演示视频。

验收：

- [ ] 整条数据链路的频率和延迟可解释。
- [ ] 规划轨迹能被 NMPC 稳定跟踪。
- [ ] 有失败重规划或安全停止机制。
